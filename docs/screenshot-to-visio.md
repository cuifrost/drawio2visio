# 从截图或 Draw.io 起稿，到可编辑 Visio

Draw.io 本身就可以直接画流程图，适合先把文字、结构和版面做好。已有清晰的 Draw.io 文件时，直接转换即可。手头只有截图时，可以让支持看图的 Agent 根据截图与补充说明重建 `.drawio`，再使用本项目输出可编辑 `.vsdx`。

## 准备输入

给 Agent 三项内容：

1. 流程图截图，包含完整节点、连线、箭头和分支标签。文字较小的区域可另外补一张局部截图。
2. 准确的补充文字：看不清的节点、判断条件、箭头方向和想调整的布局。
3. [可直接复制的完整 Agent 提示词](../prompts/screenshot-to-drawio.zh-CN.txt)。复制后把末尾的“补充文字与要求”替换为实际内容，并将截图附在同一条请求中。

提示词要求先列出节点/连线清单，再生成明文 XML，限制为转换器支持的简单形状，并检查 ID、连接引用、文字、几何和实际生效的尺寸模式。截图识别仍可能出错，需要先在 Draw.io 核对文字与流程语义。

## 先在 Draw.io 确认

打开 Agent 给出的 `.drawio`，确认开始/结束、步骤文字、“是/否”等分支方向、汇合和回路。需要更美观时，也可以直接在 Draw.io 拖动、对齐或改文字。

图形和连接必须保持为节点和连线；将截图嵌成一张图片，不能得到单独可编辑的 Visio 流程块。

## 转换与检查

假设生成的文件保存为 `outputs/reconstructed.drawio`：

```bash
node scripts/convert.js outputs/reconstructed.drawio --report-only --json
node scripts/convert.js outputs/reconstructed.drawio -o outputs/reconstructed --strict --json
python3 scripts/check_vsdx.py outputs/reconstructed.vsdx --expect "一项实际关键文字"
```

将 `--expect` 后面的示例文字换成图里实际出现的文字。网页模式也可以拖入文件、查看检查报告后导出。

统一尺寸模式适合常规流程图。若 Agent 或人工在 Draw.io 中精心设置了不同宽高、图题或长文框，给分析/转换命令都加 `--set forceSize=0`，或在网页取消“强制统一尺寸”。转换器保留纯文字，统一颜色、字体与部分形状样式；这一步是规范化交付，不是所有细节的视觉复刻。

## 在 Visio 中整理线路和间距

Visio 打开的是转换后的 `.vsdx`。维护者的实际操作经验是：有些图初次打开时连线显示凌乱，触发一次编辑重算后再统一间距，通常能省下逐个拖框和重接线的时间。

1. 在 Visio 的绘图页中按 `Ctrl+A`，确认选中了整张图的节点与连接线；如果正在编辑文字，先退出文字编辑。
2. 将选中内容轻轻拖动一小段距离并松开，保持整张图的相对结构，让 Visio 更新连接端点与线路。
3. 选中需要整理的节点，使用“开始 → 位置/排列 → 自动对齐与间距”，或打开“间距选项”设置横向、纵向间距。不同版本的菜单名称可能略有变化。
4. 多列、判断分支或回路较多时，可以先整理主干，再单独整理侧支。不要把所有节点强行分布到同一条直线上。
5. 检查节点文字、箭头、“是/否”标签、回路和连线吸附，确认后保存。

**全选轻拖是维护者提供的使用经验，尚未作为所有 Visio 版本的自动布局保证。** 简单图通常可通过整体重算、统一间距和少量微调完成交付；复杂回路、固定路线或缺失的连接关系仍需处理。

Microsoft 的 [连接线说明](https://support.microsoft.com/en-us/visio/video-connect-shapes) 介绍了形状移动时动态连接线更新连接点的行为；[对齐与间距说明](https://support.microsoft.com/en-us/visio/video-align-and-position-shapes) 提供了自动对齐、自动间距和距离设置的入口。这些说明支持一般编辑行为，并没有专门验证本项目的“全选轻拖”操作。

## 检查状态怎么写

可以写“XML/引用检查通过”“转换报告未发现警告”“在某个 Visio 版本完成了打开、移动和保存检查”。未实际运行的操作不要写成已完成；静态 SVG 预览也不应标为 Visio 客户端截图。
