# 项目定位与同类方案对比

调研日期：2026-10-13。下表依据项目公开 README 的能力声明；本次没有在统一数据集上运行所有竞品，因此不把它当作性能或兼容性排行榜。功能未在 README 展示，不等于其项目不能实现。

## 值得借鉴的呈现方式

同类项目普遍把最短运行命令放在前面，随后说明依赖、支持范围、验证方式和许可证。有些项目提供图例与实际产物，有些把工具直接包装为可安装包或 Agent Skill。好的 README 应让读者能在几分钟内验证一个完整示例，再决定是否适合自己的输入。

本次改版采用“实际效果 → 使用价值 → 最短命令 → 参数与检查 → 能力边界 → 开发贡献”的顺序；避免用内部项目经历替代公共用户能复现的示例，也不展示未经运行的成功徽章。

## 当前方案比较

| 项目 | 公开描述的实现路线 | 值得学习之处 | Drawio2Visio 的侧重点 |
|---|---|---|---|
| [Larry-Labs/drawio-to-visio](https://github.com/Larry-Labs/drawio-to-visio) | 固定 diagrams.net 26.0.16，通过 Playwright 本地导出 | 清晰说明来源、缓存、网络限制和文字校验 | 直接生成 VSDX，CLI 不需要浏览器进程或旧版导出引擎 |
| [vatsalraicha/Draw_io_To_VSDX](https://github.com/vatsalraicha/Draw_io_To_VSDX) | 标准库 Python 写 VSDX，支持多页与若干几何形状 | 可安装包、库 API、多页及结构测试 | 浏览器工作台、按类型尺寸 profile、逐项转换报告 |
| [soroshsabz/DrawioToVisio](https://github.com/soroshsabz/DrawioToVisio) | Windows + Visio COM 重建复杂图形与图标，提取 stencil | 复杂曲线/图标还原、测试分层、包装和发布 | 无 Visio 环境下的简单流程图标准化；复杂图标能力仍有明显差距 |
| [McMarius11/svgtovisio](https://github.com/McMarius11/svgtovisio) | 浏览器端 SVG/Draw.io 到 VSDX、Draw.io、FODG | 可直接使用的网页、多格式输入/输出、隐私说明 | 一致的流程图尺寸和编辑约束，检查简化、遗漏与布局风险 |

原生可编辑、本地处理、结构校验都已有其他实现，不能单独作为“别人做不到”的宣传点。是否更好用，应让同一份输入、同一份验收标准产生证据。

## 建议坚持的特色

产品定位：**面向需要规范化交付的流程图转换器，让转换结果便于继续编辑，也让转换取舍可见。**

1. 规范可以复用：流程/判定/起止各自宽高，文字标签独立，profile 明确记录实际尺寸。
2. 编辑关系可以检查：原生几何公式、Master 引用、两端 Connect 与动态触发器，均有结构检查和故障测试。
3. 转换损失可以追溯：给出源 ID、输入/输出计数、被简化形状、遗漏连线、改写线路和估算文字/重叠问题。
4. 网页和脚本结果一致：同一转换核心同时服务人工预览和自动化；严格模式提供可用的退出状态。
5. 示例可以复现：虚构中英审核流程、实际 SVG、实际工作台截图、可重建配图和测试命令。

这种能力组合可以形成特色，但本次调研不足以证明全 GitHub 唯一。当前最有说服力的证据是：公开示例输出 7 个节点、6 条连接线、12 个吸附关系；更换 profile 能实际改变输出几何与字号；问题输入被严格模式拒绝且不写产物。

## 当前差距和后续优先级

| 优先级 | 工作 | 验收方式 |
|---|---|---|
| P0 | 建立真实 Visio 编辑验收 | 打开输出，移动/缩放节点，修改文字和主题；保存前后截图与对应源文件 |
| 已完成 | 干净首发版本与 MIT 许可证 | 公共仓库从通用代码与虚构示例开始；包部件由项目源码生成 |
| P1 | 真正的多页 VSDX | 每个源页对应一个独立 Visio Page；重复 ID 不串线 |
| P1 | 提升常见几何形状支持 | 数据框、数据库、文档不用矩形替代；每类有缩放及文字测试 |
| P1 | 提升诊断精度 | 区分节点重叠、嵌套容器和线路交叉；减少文字估算误报 |
| P2 | 包装为可安装库/CLI | 无需切换仓库目录调用，支持稳定 API 与版本迁移说明 |

不建议一次扩大到完整 Draw.io 图形库、任意 SVG、反向转换和智能自动排版。先让流程图的可编辑交付在真实 Visio 中可靠，再扩大范围。
