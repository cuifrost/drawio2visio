# v0.1.0 — Initial public release

A small practical tool for the workflow: **draft in Draw.io → convert to editable Visio → inspect and refine in Visio**.

## Included

- Local browser workbench and Node.js CLI sharing the same conversion core.
- Editable VSDX flowchart shapes, master references and glued connector relationships.
- Standard/compact size presets, a publication profile, configurable font size and natural-size mode.
- Compatibility reports and a strict mode that rejects warnings before exporting.
- Explicit selection of one page from multi-page inputs.
- Structural validation, expected-text checks, fictitious examples and regression tests.
- Chinese/English README, screenshots and reproducible SVG figures.
- Project-authored VSDX parts and MIT licensing.

## Scope

The first release targets simple flowcharts. Complex icons and several shape types are simplified; source routing, groups, images and rich formatting are not fully preserved. Multi-page VSDX export and reverse conversion are not implemented. VDX and Windows COM helpers are experimental.

Passing structural checks does not replace opening the file in the intended Visio version and checking visual/editing behavior.

## Maintenance

This is a small long-term project. Updates will follow real tasks and reproducible issues as time allows, without a fixed release schedule. Minimal anonymized examples are welcome.
