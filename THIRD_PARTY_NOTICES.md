## Runtime dependency

`@xmldom/xmldom` is an XML DOM implementation, separately licensed under MIT. It is installed through npm and recorded in `package-lock.json`; dependency source is not vendored. Its own license is included in the installed package.

Project: https://github.com/xmldom/xmldom

The browser build uses the browser's DOM and stream APIs. It does not bundle diagrams.net, mxGraph or a historic Visio exporter.

## Optional Windows helper

The experimental COM path optionally installs `pywin32` on Windows. It is distributed separately under its own license; see the installed package and https://github.com/mhammond/pywin32. Microsoft Visio is a separate product and is not distributed with this repository.

## VSDX parts and examples

`scripts/build_skeleton.js` authors the minimal XML parts used by this project: simple flowchart masters, connector defaults, styles, a theme, windows and document properties. `js/vsdx-skeleton.js` is its generated artifact. No reference-document shape snapshots, binary stock icons, source-document metadata or commercial stencil packs are included.

The implementation follows public format documentation:

- https://learn.microsoft.com/en-us/office/client-developer/visio/visio-file-format-reference
- https://learn.microsoft.com/en-us/office/client-developer/visio/introduction-to-the-visio-file-formatvsdx

Font names in XML are references to fonts available on the user's system; no font binaries are bundled. Example diagrams contain fictitious content. Documentation SVGs are generated by the project's renderer; JPGs capture the project's own local browser interface.

Microsoft, Visio, JGraph, draw.io and diagrams.net names identify interoperating products only. This project is not affiliated with or endorsed by those organizations.
